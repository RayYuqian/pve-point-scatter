Points

Markers show the kept starting points.

Density

The density pattern. At Density Noise Effect 0 the markers are a random draw. Above 0, the highest scores become the markers.

Scale

The size pattern. Point Scale, Scale Border Reduction, and Scale Nose Effect turn it into the marker size.

Turbulance

Smaller detail added on top of one smooth layer. At 1, or with Voronoi, nothing extra is added, so this stays flat.
